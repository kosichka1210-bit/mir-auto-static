# Как подготовить автоматическое добавление автомобилей

Этот документ описывает следующий этап. Сейчас сайт остаётся статическим: бот, база и приём заявок ещё не включены.

## Простая схема следующего этапа

1. Представитель отправляет структурированную карточку автомобиля боту Telegram вместе с фотографиями.
2. Бот проверяет, что все обязательные поля заполнены, и сохраняет запись в MySQL.
3. Администратор при необходимости подтверждает запись в простой закрытой панели.
4. Каталог сайта получает опубликованные записи из API и автоматически показывает их в том же дизайне.
5. Статусы `В наличии`, `Под заказ` и `Продано` меняются в одном месте и сразу отражаются на сайте.

Для Timeweb Year разумно сделать это на PHP 8.x + MySQL: обычный виртуальный хостинг для этого подходит, не нужен постоянно работающий Node.js-сервер, Docker или VPS. Статическая версия сайта может остаться публичной витриной, а PHP/API появится только после подключения домена и отдельной папки сайта.

## Telegram: рекомендуемый путь

Лучше не пытаться «угадывать» свободный текст старых публикаций канала. Надёжнее, чтобы представитель добавлял машину в бота по строгой форме, а затем по желанию публиковал её в Telegram-канал. Так фотографии и поля не перепутаются.

Создание бота в BotFather:

1. В Telegram открыть `@BotFather` и отправить `/newbot`.
2. Указать имя, например `MIR AUTO Catalog`, затем уникальное имя бота, оканчивающееся на `bot`.
3. Сохранить токен бота только у себя. Его нельзя отправлять в чат, публиковать на GitHub или вставлять в файлы сайта.
4. Когда дойдём до разработки, добавить бота администратором канала, если нужны уведомления о публикациях канала.
5. Токен будет храниться только в закрытом конфигурационном файле на Timeweb вне публичной папки сайта.

## Шаблон сообщения для добавления автомобиля

Сначала прикрепить от 1 до 10 фотографий автомобиля, затем отправить боту текст по шаблону:

```text
Марка: Hyundai
Модель: Elantra GLX Elite
Год: 2023
Пробег: 12 800 км
Двигатель: 1,5 л, 115 л.с.
Привод: передний
Коробка: CVT
Цена: 1 515 000 ₽
Статус: Под заказ
Описание: Люк, кожаный салон, мультимедиа. Хорошее состояние.
```

Поле `Цена` можно оставить пустым: тогда сайт покажет «Стоимость уточняйте», а не выдумает значение. Поле `Статус` — только одно из заранее заданных: `В наличии`, `Под заказ`, `Продано`.

## Какие данные нужно решить до разработки

- Кто имеет право добавлять и редактировать автомобили.
- Нужна ли ручная модерация до появления автомобиля на сайте.
- Какие статусы использовать и когда переводить автомобиль в «Продано».
- Что показывать публично: цену, цену «под ключ» или «уточняйте».
- Какие фотографии считаются обязательными: одна обложка или галерея.
- Какой домен будет у сайта: после покупки заменим временные адреса GitHub Pages в SEO, sitemap и Open Graph.

## MAX

MAX сейчас стоит оставлять как канал связи. Для первой автоматизации безопаснее сделать Telegram основным источником: у Telegram есть зрелый официальный Bot API и вебхуки. MAX можно подключать позже только после проверки доступного официального API и нужных прав доступа — не стоит строить на нём критическую часть каталога заранее.

## Безопасность

- Токен Telegram, пароль MySQL, FTP/SSH-пароли и ключи не хранятся в коде, GitHub или браузере.
- В публичный репозиторий попадает только интерфейс и безопасные примеры конфигурации.
- Закрытые параметры хранятся на Timeweb в файле вне `public_html` либо в настройках окружения.
- Бот принимает сообщения только от разрешённых аккаунтов; все поля валидируются.

## Что потребуется от вас в день подключения

1. Админ-доступ к Telegram-каналу и созданный бот в BotFather.
2. Возможность добавить бота администратором канала.
3. Доступ к отдельному сайту/папке MIR AUTO на Timeweb и к MySQL.
4. Решение по шаблону карточки и статусам.
5. Купленный домен — не обязателен для разработки, но нужен перед финальным запуском.
