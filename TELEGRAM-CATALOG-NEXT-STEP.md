# Каталог MIR AUTO: следующий этап — Telegram → сайт

Сейчас каталог является статической витриной: в нём 8 реальных опубликованных предложений. Это корректно для запуска, но добавление новой машины требует ручного обновления файлов. Для коммерческой работы следующий этап стоит строить на **PHP 8 + MySQL + Telegram webhook** на обычном виртуальном хостинге Timeweb Year.

Такой вариант не требует VPS, Docker или постоянно запущенного Node.js-сервера. Telegram отправляет новое сообщение на защищённый PHP-адрес (webhook), PHP сохраняет данные в MySQL, а сайт получает готовые карточки из каталога.

## Что будет сделано на этапе интеграции

```text
Владимир / Олег → Telegram-бот → PHP webhook на Timeweb → MySQL → каталог MIR AUTO
```

1. Представитель отправляет боту команду `/addcar`.
2. Бот по шагам просит данные автомобиля и до 10 фотографий.
3. Бот проверяет обязательные поля и показывает предварительный просмотр.
4. После подтверждения запись попадает в MySQL со статусом `Под заказ`, `В наличии` или `Продано`.
5. Карточка появляется в каталоге сайта; отдельная страница автомобиля строится по той же информации.
6. Команды `/edit`, `/sold` и `/delete` меняют данные только у разрешённых представителей.

На первом этапе лучше **не читать старые публикации канала автоматически**. Их свободный формат и альбомы фотографий могут быть неполными. Надёжнее отправлять машину боту лично, а затем при желании публиковать готовый текст в канал. Бота не нужно добавлять в канал для такого личного сценария.

## Что нужно сделать в Telegram

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте команду `/newbot`.
3. Укажите понятное имя, например `MIR AUTO Catalog`.
4. Придумайте уникальное имя, которое заканчивается на `bot`, например `mir_auto_catalog_bot`.
5. BotFather выдаст **токен** — длинную строку. Сохраните её в менеджере паролей или заметке с ограниченным доступом.

Токен нельзя отправлять в общий чат, присылать в Telegram-канал, публиковать на GitHub, вставлять в HTML или показывать на скриншотах. Он даёт полный доступ к боту. В работе он будет сохранён на Timeweb в закрытом конфигурационном файле вне публичной папки сайта.

После создания бота сначала напишите ему лично `/start`. Так можно узнать ваш Telegram ID и добавить его в список разрешённых пользователей. Добавлять бота в канал на старте не нужно. Это потребуется позднее, только если MIR AUTO захочет публиковать в канал уведомления автоматически.

## Удобный сценарий добавления машины

1. Откройте диалог с ботом.
2. Нажмите или отправьте `/addcar`.
3. Бот предложит заполнить поля по очереди и прикрепить фотографии.
4. Проверьте предварительный просмотр и подтвердите публикацию.
5. Откройте каталог сайта: новая карточка должна появиться без ручного редактирования HTML.

Если удобнее начать не с диалога, а с одного сообщения, допустим также такой шаблон. К сообщению прикрепляются фотографии автомобиля:

```text
Марка: Hyundai
Модель: Elantra GLX Elite
Год: 2023
Пробег: 12 800 км
Двигатель: 1,5 л, 115 л.с.
Привод: передний
Коробка: CVT
Комплектация: GLX Elite
Цена: 1 515 000 ₽
Цена указана для: Владивостока
Статус: Под заказ
Город / расчёт: Владивосток
Описание: Краткая проверенная информация об автомобиле.
Недостатки / особенности: Указать известные особенности, если есть.
Фото: прикреплены к сообщению
```

Поле цены можно оставить пустым: сайт в таком случае покажет «Уточняйте актуальность предложения», а не придумает сумму. Обязательные поля: марка, модель, год, статус и хотя бы одно фото. Остальные поля бот будет разрешать пропустить.

## Команды и кнопки бота

- `/addcar` — добавить автомобиль;
- `/cars` — показать последние добавленные автомобили;
- `/edit` — изменить данные выбранного автомобиля;
- `/sold` — отметить автомобиль как проданный;
- `/delete` — удалить ошибочную или снятую с публикации карточку;
- `/help` — показать инструкцию.

В реальном интерфейсе команды дополнятся кнопками: «Добавить», «Мои автомобили», «Изменить статус», «Продано». Для `/sold` бот попросит выбрать автомобиль и подтвердить изменение, чтобы не пометить карточку случайно.

## Безопасность и права доступа

- Бот принимает команды только от Telegram ID Владимира, Олега и при необходимости владельца сайта.
- Telegram ID добавляются в закрытый файл настроек на Timeweb, а не в открытый GitHub-репозиторий.
- Токен бота и пароль MySQL находятся только в конфигурации на хостинге вне публичного каталога сайта.
- Фотографии проходят проверку типа и размера, а текст — проверку длины и обязательных полей.
- До подтверждения карточка имеет черновой статус; публикация возможна только после действия разрешённого представителя.

## Что потребуется от заказчика перед началом разработки

1. Созданный бот и токен, переданный безопасным способом в момент настройки, а не в общий чат.
2. Telegram ID Владимира и Олега (бот сможет показать их после `/start`).
3. Решение: Владимир остаётся основным представителем на сайте и в боте или это нужно изменить.
4. Подтверждение списка статусов: `В наличии`, `Под заказ`, `Продано`.
5. Решение, какая цена показывается публично: для Владивостока, «под ключ» или только «уточняйте».
6. Доступ к отдельной папке/сайту MIR AUTO и MySQL на Timeweb. Нельзя использовать папку другого клиента.
7. Домен, когда он будет куплен. Для разработки он не обязателен; для финального webhook и SEO лучше подключить его до запуска.

## Порядок запуска на Timeweb Year

1. Создать отдельную базу MySQL для MIR AUTO.
2. Разместить закрытую конфигурацию и PHP webhook вне публичной веб-папки.
3. Подключить webhook по HTTPS на домене MIR AUTO.
4. Добавить разрешённые Telegram ID.
5. Протестировать одну черновую карточку и одну карточку со статусом «Продано».
6. После проверки включить публичное отображение каталога.

MAX на этом этапе остаётся каналом связи. Его не стоит делать источником каталога, пока нет проверенного официального API и прав доступа. Основой автоматизации будет Telegram Bot API.
