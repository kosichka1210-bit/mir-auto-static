# Telegram-бот каталога MIR AUTO

Готовая основа для Timeweb Year: PHP 8.x, MySQL и Telegram webhook. VPS, Docker и постоянно работающий Node.js не нужны.

## Что уже умеет основа

- принимает команды только в личной переписке с ботом;
- разрешает работу только Telegram ID из закрытого списка;
- пошагово собирает марку, модель, год, характеристики, цену и статус;
- принимает от 1 до 10 фотографий и сохраняет их на Timeweb;
- показывает предварительный просмотр;
- публикует автомобиль в MySQL только после подтверждения;
- отдаёт опубликованные автомобили через публичный JSON API для будущего подключения каталога сайта;
- не хранит токен Telegram или пароль MySQL в GitHub и публичной папке.

## Как будет работать для Владимира и Олега

1. Открыть личный диалог с ботом.
2. Нажать «Добавить автомобиль» или отправить `/addcar`.
3. Ответить на вопросы. Неизвестные данные можно пропустить.
4. Отправить фотографии автомобиля.
5. Нажать «Готово», проверить карточку и нажать «Опубликовать».
6. Запись появится в базе. После подключения сайта к API она автоматически появится в каталоге.

Бота не нужно добавлять администратором Telegram-канала: автомобили отправляются ему в личные сообщения. Канал MIR AUTO остаётся без изменений.

## Шаг 1. Создать бота в BotFather

1. В Telegram открыть официальный аккаунт `@BotFather`.
2. Отправить `/newbot`.
3. Указать имя, например `MIR AUTO Каталог`.
4. Указать уникальное имя, оканчивающееся на `bot`, например `mir_auto_catalog_bot`.
5. BotFather выдаст токен.

Токен нельзя присылать в общий чат, добавлять в GitHub, HTML сайта или показывать на скриншоте. Он записывается только в закрытый файл на Timeweb.

## Шаг 2. Подготовить MySQL на Timeweb

В панели Timeweb открыть «Базы данных» и создать отдельную базу для MIR AUTO. Сохранить:

- имя базы;
- имя пользователя базы;
- пароль;
- адрес сервера базы, обычно `localhost` на том же хостинге.

Затем открыть phpMyAdmin, выбрать новую базу и импортировать файл `database/schema.sql`.

## Шаг 3. Разместить файлы отдельно от сайта другого клиента

Использовать только отдельную папку MIR AUTO:

```text
mir-auto/
├─ private/
│  ├─ config/config.php
│  ├─ src/
│  └─ storage/drafts/
└─ public_html/
   ├─ bot/webhook.php
   ├─ api/cars.php
   └─ media/cars/
```

Содержимое папки `telegram-bot/private` загрузить в `mir-auto/private`. Содержимое `telegram-bot/public` загрузить в существующую папку `mir-auto/public_html`, не удаляя файлы сайта. Папку `telegram-bot/tools` загрузить в `mir-auto/tools`.

## Шаг 4. Создать закрытую конфигурацию

На Timeweb скопировать:

```text
private/config/config.example.php → private/config/config.php
```

В `config.php` указать:

- токен BotFather;
- длинную случайную строку `webhook_secret`;
- Telegram ID допущенных людей;
- имя, пользователя и пароль MySQL;
- HTTPS-адрес сайта.

Файл `config.php` находится вне `public_html`, поэтому посетители сайта открыть его не смогут.

## Как узнать Telegram ID

До включения ограничений можно временно оставить свой ID в списке, открыть бота и написать `/start`. Если ID ещё не разрешён, бот ответит числом вида `123456789`. Это число нужно внести в `allowed_user_ids`.

То же делают Владимир и Олег: каждый открывает бота, нажимает Start и передаёт владельцу сайта только свой числовой ID. Токен бота им не нужен.

## Шаг 5. Проверить сервер и включить webhook

Через SSH-консоль Timeweb из папки `mir-auto` выполнить:

```bash
php tools/check.php
php tools/set-webhook.php https://ВАШ-ДОМЕН/bot/webhook.php
```

Telegram принимает webhook только по публичному HTTPS-адресу. Купленный домен удобнее, но можно начать с технического HTTPS-домена Timeweb, если он выдан для отдельного сайта MIR AUTO.

## Шаг 6. Проверить тестовую карточку

1. Разрешённый пользователь пишет боту `/start`.
2. Добавляет тестовый автомобиль с реальными данными и хотя бы одной фотографией.
3. Проверяет предварительный просмотр.
4. Публикует карточку.
5. Открывает `https://ВАШ-ДОМЕН/api/cars.php` — в ответе должна появиться запись и адрес фотографии.

Пока текущий сайт работает на GitHub Pages, его статические карточки остаются без изменений. Последним шагом интеграции будет подключение каталога к этому API с сохранением текущего дизайна и резервным показом существующих восьми карточек.

## Команды первой версии

- `/start` и `/help` — инструкция и кнопки;
- `/addcar` — новая карточка;
- `/cars` — последние 10 автомобилей;
- `/cancel` — отменить текущий черновик.

Изменение статуса, редактирование и удаление добавляются после проверки основного сценария, чтобы сначала безопасно протестировать публикацию и не дать случайно удалить автомобиль.

## Что ещё нужно для реального запуска

- созданный бот в BotFather;
- токен, внесённый прямо на Timeweb без публикации;
- Telegram ID Владимира, Олега и владельца сайта;
- отдельная база MySQL MIR AUTO;
- технический или купленный HTTPS-домен MIR AUTO;
- подтверждение публичных статусов и правил отображения цены.
